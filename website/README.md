# Hark website

Static Astro site, hosted on S3 behind CloudFront, provisioned with CDK.
Same shape and same AWS profile (`radius`) as the sibling project sites.

```sh
npm install                 # once
npm run dev                 # http://localhost:4321
scripts/deploy.sh           # infra + build + sync + invalidate
```

`infra/` is a separate npm package holding the CDK app (`npm install` there
too, once). The first deploy bootstraps nothing new: the radius account is
already CDK-bootstrapped in us-east-1 by the sibling sites.

## Domain

harkdictate.com is registered in the radius account, so its Route 53
hosted zone exists and `deploy.sh` defaults `SITE_DOMAIN` to it: the stack
holds the ACM certificate (DNS-validated, us-east-1), the CloudFront
aliases, and the apex and www A/AAAA records. The CloudFront URL keeps
working alongside, so nothing that pinned it breaks.

## Brand assets

`public/brand/`, `public/favicon.svg`, `public/apple-touch-icon.png` and
`public/og/card.png` are generated by `tools/mark/build-assets.py` from the
source SVGs in `docs/brand/source/`. Edit the sources, run the script, commit
the outputs. Colors and rules are in `docs/brand.md`.
